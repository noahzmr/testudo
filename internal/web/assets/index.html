Interfaces · live kernel state

All kernel-visible interfaces are monitored. Errors / drops / collisions and a per-radio WiFi badge sit alongside the link state so a degraded NIC is obvious before flows go silent. Addresses, DHCP, MTU and link state are configured in the model, under Configuration above.

NameStateTypeMTUHW addrAddresses RXTX RX errTX errDropsColl. WiFi

WiFi · wireless link quality

One card per radio with a computed link-quality grade (RSSI + SNR + TX-failure blend), live signal, PHY bitrate, and the full nl80211/iw counter set. The grade looks beyond raw signal: a strong-signal link with a high retry/failure rate still grades down.
