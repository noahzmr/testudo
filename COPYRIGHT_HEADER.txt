USAGE RULES
--------------------------------------------------------------------------------

1. Every new source file must include the header before its first
   declaration, in the language-appropriate comment form above.

2. The "Created" field is set once, when the file is first added to the
   repository, and never changed. The "Updated" field is bumped on
   substantive edits - typo fixes, formatting passes, and dependency
   bumps do not require it.

3. When updating an existing file with a meaningful change, advance the
   "Updated" date to the current date in ISO 8601 form (YYYY-MM-DD).
   Leave the "Created" date untouched.

4. The SPDX-License-Identifier line is mandatory - automated tooling
   relies on it. Do not remove it when stripping comments for minified
   builds; preserve it in a build-tool license banner instead.

5. Do not remove copyright headers from contributed source files. This
   is required by MPL-2.0 Section 3.4 and reinforced by Section 7 of
   the NOTICE file.

6. Third-party files vendored into the repository keep their original
   upstream headers. Do not replace upstream headers with this one.
